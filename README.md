# VR-Glove
A glove with sensors to detect hand movements to use un VR

## Description
This project is a glove with sensors to detect hand movements to use in VR.
The materials you will need are:
- Circuit Playground Express
- 5 flex sensors
- 1 BNO055 IMU
- Fabric, I used polyester lining and thin neoprene.
- Conductive thread

## Construction steps
1.	Redraw pattern with final modifications ✓
2.	Draw pattern into the lining ✓
3.	Stitch the circuit lines into the lining, slack cables go in the front ✓
4.	Prepare the thumb sensor ✓
5.	Stitch thumb sensor into outer layer, being very careful on the position. ✓
6.	Put together lining and the other outer layer and stitch the flex sensor channels ✓
7.	Stitch all the sensors now.
8.	Align the final layer, being careful to align thumb sensor, use pins for this
9.	Layers should go:
    a.	Thumb sensor
    b.	Palm layer
    c.	Reverse layer, sensors facing palm layer
    d.	Lining
10.	Pin the layers and cut the rough shape
11.	Stitch the glove
12.	Cut the correct shape VERY CAREFUL WITH THUMB SENSOR FLAPS
13.	Sew thumb sensor flaps to cables and use glue to keep in place
14.	Hem
15.	Reverse
16.	Done
17.	Extra, add a Velcro strap.
